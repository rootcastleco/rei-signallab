# REI SignalLab 2.1.0 Release Notes

We are thrilled to announce **REI SignalLab 2.1.0**, a major release bringing an extended canonical typed DSP node library, Kahn's topological graph execution engine, numerical golden precision verification, and the **REI Vibration Analysis Workbench**!

---

## 🚀 Key Highlights & New Features

### 1. Extended Canonical Typed DSP Node Library (`.rei-signal 2.1`)
- **Versioned Node Registry (`GET /api/nodes`)**: Exposes 35+ canonical DSP and Vibration nodes with strictly typed input/output ports (`Signal<Real64>`, `Signal<Complex128>`, `SpectrumFrame`, `Scalar<Real64>`, `PatternEvent`).
- **Kahn's Topological Execution Engine (`POST /api/graph/execute`)**: 10-point port compatibility validator, feedback cycle detector (`HTTP 422 GRAPH_CYCLE_DETECTED`), and deterministic Kahn scheduler.

### 2. REI Vibration Analysis Workbench
- **IEPE Accelerometer Calibration**: Converts raw voltage to engineering units ($\text{mV/g}$, $\text{g}$, $\text{m/s}^2$).
- **High-Pass Regularized Integration**: Frequency-domain integration converting acceleration ($\text{m/s}^2$) to velocity ($\text{mm/s RMS}$) and displacement ($\mu\text{m}$) without low-frequency drift.
- **Kinematic Bearing Defect Frequencies**: Exact calculations for BPFO, BPFI, BSF, and FTF from bearing geometry parameters ($N, d, D, \phi$).
- **Single-Plane Complex Vector Rotor Balancing**: Solves influence coefficient matrix ($\vec{V}_0, \vec{V}_1, \vec{W}_{\text{trial}} \to \vec{W}_{\text{correction}}$) rendering polar vector balance plots.
- **1X-10X Harmonic Order Spectrum Bar View**: Interactive order spectrum bar view displaying fundamental shaft speed 1X, misalignment 2X, looseness 3X, and up to 10X harmonics.
- **Rule-Based Machine Fault Classifier**: Evaluates spectral evidence for Unbalance, Angular/Parallel Misalignment, Looseness, and Bearing Defects.
- **Automated Vibration Diagnostic Report Exporter**: Exports machine metadata, bearing frequencies, balance solutions, and diagnostic evidence in JSON format.

### 3. Numerical Golden Verification Suite
Comprehensive Pytest test suite verifying numerical tolerances against NumPy/SciPy reference standards (`backend/tests/test_golden.py` & `backend/tests/test_vibration_golden.py`):
- **Float64 Precision**: $|x_{\text{computed}} - x_{\text{reference}}| \le 1.0 \times 10^{-12}$
- **FFT / IFFT Reconstruction RMS Error**: $RMS \le 1.0 \times 10^{-9}$
- **DCT Type II Reconstruction Error**: $RMS \le 1.0 \times 10^{-12}$
- **Haar Wavelet Reconstruction Error**: $RMS \le 1.0 \times 10^{-12}$
- **Sensor Calibration & Bearing Frequency Relative Error**: $\le 0.1\%$
- **Velocity Integration Relative Error**: $\le 1.0\%$
- **Rotor Balancing Precision**: Mass error $\le 1.0\%$, Angle error $\le 1.0^\circ$

### 4. Custom Preset Management
- **Save Custom Presets**: Save current waveform, filter, math, and FFT configurations under custom names.
- **`localStorage` Persistence**: Custom presets persist across browser refreshes and tab reopens.
- **Preset Management UI**: Optgroup select dropdown with deletion capabilities.
